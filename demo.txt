Q3. What is dynamic typing? What are type hints?
EXPLANATION
In a statically typed language (Java, C++) you must write the type: int x = 10;. The type is checked before the program runs.
In a dynamically typed language like Python, a variable is just a name that points to an object. The object has a type, the name does not. So the same name can point to an int now and a string later. Type errors are found only when that line runs.
Python is also strongly typed. It does not silently mix incompatible types. For example "5" + 5 gives a TypeError; Python will not guess.
x = 5
x = "five"          # fine, dynamic typing
 
print("5" + 5)      # TypeError: can only concatenate str (not "int") to str
print("5" + str(5)) # "55"  (explicit conversion)
 
# Type hints (Python 3.5+), only for readability and tools; NOT enforced at run time
def add(a: int, b: int) -> int:
    return a + b
 
print(add("a", "b"))  # still runs and prints "ab"

Advantage of dynamic typing: faster to write, less code. Disadvantage: bugs may appear only at run time, and it is harder to maintain in big projects. Type hints help with that.
HOW TO SAY IT IN THE INTERVIEW
"In Python, a variable is a name that refers to an object, and the type belongs to the object. So I do not declare types, and the same variable can hold different types at different times. That is dynamic typing.
Python is still strongly typed, so it will not add a string and an integer without conversion. I also use type hints in function signatures to make the code more readable, but Python does not enforce them at run time."
